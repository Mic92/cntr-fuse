# cntr-fuse (DEPRECATED)

**This crate is deprecated and unmaintained.**

cntr-fuse was a fork of the [fuse](https://crates.io/crates/fuse) crate with functionality needed for [cntr](https://github.com/Mic92/cntr). As of cntr 2.0, cntr no longer uses FUSE and instead uses the Linux mount API directly.

## Alternatives

If you need a FUSE library for Rust, consider:

- [fuser](https://crates.io/crates/fuser) - actively maintained FUSE library for Rust
